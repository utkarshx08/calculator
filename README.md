# Tkinter Calculator

A simple desktop calculator built with **Python** and **Tkinter** for performing basic arithmetic operations through a graphical user interface.

## Features

* Addition
* Subtraction
* Multiplication
* Division
* Decimal calculations
* Parentheses
* Clear display
* Basic error handling
* Simple and user-friendly GUI

## Technologies Used

* **Python 3**
* **Tkinter**

## How to Run

1. Clone the repository:

```bash
git clone https://github.com/utkarshx08/calculator
```

2. Open the project directory:

```bash
cd calculator
```

3. Run the application:

```bash
python calculator1.py
```
